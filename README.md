## What is webburnshub?

**webburnshub** is the official public release hub of [WebburnsTech (Webburns Technologies)](https://github.com/WebburnsTech) — a digital solutions company based in Hyderabad, India.

Every product, package, SDK, CLI tool, and platform released by WebburnsTech lives here. This is where you find stable releases, changelogs, versioned packages, and the entry point to the entire WebburnsTech ecosystem — from AI developer tools to open-source learning platforms.

Whether you're a developer integrating our packages, a student using our platforms, or a contributor looking to get involved, **this is your starting point.**

## Contributing

We welcome contributions across all platforms — bug fixes, features, documentation, design, translations, and testing.

**How to contribute:**

1. Read the [Contributing Guide](https://github.com/register360/webburnstech.com/blob/main/CONTRIBUTING.md)
2. Review the [Code of Conduct](https://github.com/register360/webburnstech.com/blob/main/CODE_OF_CONDUCT.md)
3. Check open issues for [good first issues](https://github.com/register360/webburnstech.com/labels/good%20first%20issue)
4. Fork, branch, and open a pull request

**Contribution areas:**

- 🐛 Bug fixes
- ✨ New features and platform improvements
- 📝 Documentation and tutorials
- 🎨 UI/UX design
- 🌐 Translations and localisation
- 🧪 Testing and QA

Contributors are credited in [AUTHORS.md](https://github.com/register360/webburnstech.com/blob/main/AUTHORS.md), release notes, and social shoutouts.
